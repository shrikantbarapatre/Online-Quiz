# Online Quiz Application (Java)

This is a simple console-based quiz application built using Java.

## Features
- Multiple Choice Questions
- User Input Handling
- Score Calculation
- Instant Result

## Technologies Used
- Java
- VS Code
- Git & GitHub

## How to Run

Compile the program:

```
javac OnlineQuiz.java
```

Run the program:

```
java OnlineQuiz
```
